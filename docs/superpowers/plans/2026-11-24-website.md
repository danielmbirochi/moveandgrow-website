# Move and Grow Website Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A six-page static marketing site in Brazilian Portuguese whose whole visual identity is selected in `visual-identity.config.ts`.

**Architecture:** Astro static site. Theme objects in `src/themes/` are converted to CSS custom properties at build time; Tailwind maps semantic utility names onto those variables, so components never hold a raw colour, font or radius. Copy lives in typed content modules under `src/content/`, separate from layout.

**Tech Stack:** Astro (latest stable), Tailwind CSS, TypeScript, npm, Fontsource (self-hosted fonts), Vitest, `@astrojs/sitemap`.

**Spec:** `docs/superpowers/specs/2026-11-24-website-design.md`. Read it fully before Task 1. It holds every colour value, every line of approved copy and the anti-goals.

## Global Constraints

- Language `pt-BR`; Astro i18n configured with `defaultLocale: 'pt-br'`, `locales: ['pt-br']`, default locale unprefixed.
- Brand name `Move and Grow`, short name `M.G.`, read from `visual-identity.config.ts` only. No component or content file hard-codes the name.
- Default theme `oficina`. Setting `activeTheme` to `sistema` and rebuilding restyles the whole site with no other edit.
- No raw hex colour, font-family name or pixel radius in any file under `src/components/`, `src/layouts/` or `src/pages/`.
- Approved copy from the spec is used verbatim. Any line the builder writes is listed in `docs/copy-additions.md`.
- Forbidden on the site: client logos, testimonials, case numbers, prices, capacity statements, stock photos, and the vocabulary in the spec's "Avoid" column (the approved headline "Você não precisa começar do zero" is the one allowed use of "do zero").
- Fonts are self-hosted; no request to a third-party host at runtime. No analytics, no cookies.
- Contact placeholders `[EMAIL]` and `[WHATSAPP]` and site URL `https://example.com` live in `src/site.config.ts` only.
- Text contrast 4.5:1 or better (3:1 at 24px and larger) in both themes.
- Lighthouse mobile 95+ in all four categories on every page.
- Commit after each task with a conventional message. Do not push; there is no remote.

## Review Focus

1. **Unconfigured contact details.** With `[EMAIL]` / `[WHATSAPP]` still placeholders, the form and contact links must not produce broken `mailto:[EMAIL]` or `wa.me/[WHATSAPP]` links; they show a visible "contato em configuração" state instead. Test in Task 5.
2. **Narrow screens.** At 360px, long Portuguese headlines and the four-column offers table must not cause horizontal scroll. Test in Task 6.
3. **JavaScript disabled.** The contact form still submits through its `mailto:` action, and navigation works. Test in Task 5.
4. **Theme B legibility.** Accent-on-ground and muted-on-surface pairs in `sistema` must meet contrast, not only `oficina`. Test in Task 1.
5. **A theme missing a token.** A theme object lacking a role must fail the build with a message naming the token, not ship an unstyled page. Test in Task 1.

**Interfaces:**
- Produces:
  - `visual-identity.config.ts`: `export const activeTheme: ThemeName = 'oficina'` and `export const brand = { name: 'Move and Grow', shortName: 'M.G.' }`
  - `type ThemeName = 'oficina' | 'sistema'`
  - `type Theme = { name: ThemeName; colors: Record<ColorRole, string>; fonts: { heading: FontSpec; body: FontSpec; label: FontSpec }; radii: { control: string; card: string; pill: string }; style: { label: 'mono' | 'pill'; numbered: 'rule' | 'circle'; card: 'outline' | 'filled' } }`
  - `ColorRole`: `ground`, `ink`, `surface`, `surfaceRaised`, `muted`, `body`, `accent`, `onAccent`, `accentText`, `accentTextOnInverse`, `border`, `inverseGround`, `inverseInk`
  - `FontSpec = { family: string; weights: number[]; fontsource: string }`
  - `resolveTheme(name?: ThemeName): Theme` (argument, else `process.env.MG_THEME`, else `activeTheme`; throws `Missing theme token: <path>` when a role is absent)
  - `themeToCssVars(theme: Theme): Record<string, string>` with keys such as `--color-ground`, `--font-heading`, `--radius-card`
  - `contrastRatio(hexA: string, hexB: string): number`
  - Tailwind utilities named after roles: `bg-ground`, `bg-surface`, `text-ink`, `text-muted`, `bg-accent`, `text-on-accent`, `border-border`, `font-heading`, `font-body`, `font-label`, `rounded-control`, `rounded-card`, `rounded-pill`
  - `data-label`, `data-numbered`, `data-card` attributes on `<html>` carrying the theme's `style` switches

```ts
import { describe, it, expect } from 'vitest';
import { resolveTheme, themeToCssVars, contrastRatio } from '../src/themes';
import { oficina } from '../src/themes/oficina';

describe('themes', () => {
  it('defaults to oficina', () => {
    expect(resolveTheme().name).toBe('oficina');
  });
  it('maps oficina colours from the spec', () => {
    const v = themeToCssVars(resolveTheme('oficina'));
    expect(v['--color-ground']).toBe('#FFFFFF');
    expect(v['--color-ink']).toBe('#0E1B2A');
    expect(v['--color-accent']).toBe('#FF5A1F');
    expect(v['--radius-control']).toBe('2px');
  });
  it('maps sistema colours from the spec', () => {
    const v = themeToCssVars(resolveTheme('sistema'));
    expect(v['--color-ground']).toBe('#12102E');
    expect(v['--color-accent']).toBe('#6C4DFF');
    expect(v['--radius-control']).toBe('12px');
  });
  it.each(['oficina', 'sistema'] as const)('%s meets text contrast', (name) => {
    const c = resolveTheme(name).colors;
    expect(contrastRatio(c.ink, c.ground)).toBeGreaterThanOrEqual(4.5);
    expect(contrastRatio(c.muted, c.ground)).toBeGreaterThanOrEqual(4.5);
    expect(contrastRatio(c.muted, c.surface)).toBeGreaterThanOrEqual(4.5);
    expect(contrastRatio(c.body, c.surface)).toBeGreaterThanOrEqual(4.5);
    expect(contrastRatio(c.onAccent, c.accent)).toBeGreaterThanOrEqual(4.5);
    expect(contrastRatio(c.accentText, c.ground)).toBeGreaterThanOrEqual(4.5);
    expect(contrastRatio(c.inverseInk, c.inverseGround)).toBeGreaterThanOrEqual(4.5);
    expect(contrastRatio(c.accentTextOnInverse, c.inverseGround)).toBeGreaterThanOrEqual(4.5);
  });
  it('names the missing token', () => {
    const broken = structuredClone(oficina) as any;
    delete broken.colors.accent;
    expect(() => themeToCssVars(broken)).toThrow('Missing theme token: colors.accent');
  });
});
```
